## 🚀 Open-source projects

| Project | What it is |
|---|---|
| **[MARS-Curiosity](https://github.com/andrea-magni/MARS)** | REST framework for Delphi — JAX-RS style resources, routes, server & client, JWT, OpenAPI 3, FireDAC/Devart, SSE and **MCP servers for AI agents**. Runs on Windows, MacOS, Linux and Docker. |
| **[TFrameStand](https://github.com/andrea-magni/TFrameStand)** | `TFrameStand` / `TFormStand` — clean, animated, stylable navigation between frames and forms in FireMonkey. |
| **[FMXER](https://github.com/andrea-magni/FMXER)** | A Flutter-inspired, declarative way to build FMX user interfaces. |
